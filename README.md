# Pebbl

> **Pebbl** is an interactive web platform designed for local community engagement, interest-based clubs, and real-time mapping. Built for the hackathon, Pebbl helps users discover local activities, connect with like-minded people, and stay engaged with their community.

---

## Key Features

### Landing & Onboarding Page
- **Hero & Mission Statement:** Introduces users to the Pebbl ecosystem and core values.
- **Seamless Onboarding:** Quick access for new users to explore communities and feature highlights.

### Community Feed
- **Interactive Posts:** Share updates, images, and thought-pieces with your community.
- **Real-Time Interactions:** Like, comment, and engage with community members.
- **Content Filtering:** Easily switch between top, recent, and relevant community posts.

### Interactive Community Map
- **Local Event Discovery:** Pin and locate nearby interest clubs, gathering spots, and events.
- **Geographic Filtering:** Explore activities based on proximity and specific categories.

### Interest-Based Clubs
- **Join & Create Clubs:** Discover existing groups (e.g., sports, arts, tech) or start your own.
- **Club Hub:** Dedicated spaces for club-specific events, announcements, and member rosters.

### User Profiles & Settings
- **Customizable Profiles:** Show off your joined clubs, badges, and activity history.
- **Account Management:** Update user preferences, profile details, and privacy settings.

---

## Tech Stack & Architecture

- **Frontend Framework:** React 18
- **Build Tooling:** [Vite](https://vitejs.dev/) (Fast HMR & build bundling)
- **Styling:** CSS Modules / Modern CSS3
- **Routing:** React Router
- **Deployment & Hosting:** [Netlify](https://www.netlify.com/)
